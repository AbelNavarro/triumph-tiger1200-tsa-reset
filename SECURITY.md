# Security and responsible reporting

This software interacts with a vehicle ECU. Report possible unintended writes, unsafe state transitions, data leaks and access-control concerns privately to the maintainer using GitHub private vulnerability reporting if enabled. If unavailable, request a private contact route without including sensitive details in a public issue.

Do not post seed/key captures, access secrets, VINs, serials or techniques for unauthorized access in issues. Manufacturer-level security issues should be coordinated with the affected manufacturer.

# Contributing

Contributions to read-only diagnostics, transport validation, offline simulations and documentation are welcome. Include reproduction steps and synthetic or carefully redacted evidence.

Please distinguish live results, owner observations, hypotheses and static analysis. Do not upload proprietary firmware, app binaries, decompiled source, commercial manuals, vehicle identifiers or security secrets. Do not submit unreviewed live-write commands. Every proposed write operation must be assessed for physical safety, scope and compatibility before inclusion.

Run offline tests and document limitations. Do not run physical-bike tests from CI.
